
# Mini 3D GTA Live Demo

This is a small 3D GTA-like playground using Three.js.

## How to host on GitHub Pages
1. Create a GitHub repository (e.g., `gta-live-demo`).
2. Upload all files from this folder.
3. Go to `Settings -> Pages` in your repo.
4. Set branch: `main` and folder: `/root`.
5. GitHub Pages will provide a URL to play the demo live.

## Controls
- Click to lock pointer
- WASD: move/drive
- Mouse: look
- E: enter/exit vehicle
- Space: handbrake
